## 🚀 Installation

### Quick Install

Simply click the link below and Raycast will automatically import the theme:

```
https://ray.so/themes?version=1&name=Tokyo%20Night%20Storm&author=flight505&authorUsername=flight505
```

### Manual Installation

1. Copy the theme installation link above
2. Paste it into your browser
3. If Raycast is installed, it will automatically open and prompt you to install the theme
4. Click **Install Theme** to apply

## 🎨 Color Palette

This theme uses the authentic Tokyo Night Storm color scheme:

| Element | Color | Hex |
|---------|-------|-----|
| Background | Deep Navy | `#24283b` |
| Foreground | Soft White | `#c0caf5` |
| Primary Accent | Storm Blue | `#7aa2f7` |
| Success | Spring Green | `#9ece6a` |
| Warning | Autumn Gold | `#e0af68` |
| Error | Red Spider Lily | `#f7768e` |
